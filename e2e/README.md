# 携帯幅の主線

架空のデモ家庭を使い、390 × 844 で「決める」から選び直しと取り消しの草稿までを通す。
「すること」を足してやり方を選び、「選んだら」を見て本命を選び、「送った」と記録して返事を待つ道筋も通す。
まだ合うやり方が無い時に、頼める人とやり方を登録し、本命に選んで作業を確かめる道筋も通す。
送った「すること」を直す・要らないにする前に変わることを見て、取り消しの文が送った時の控えに戻る道筋も通す。
候補日を相手がリンクから答え、家族が最新の答えを読んで日を決め、やり方に進む道筋を、育児と集まりの両方で通す。
別々のブラウザで見える範囲と、リンクを出し直した時に前の物が使えないこと、同じタブで別のリンクを開くことも確かめる。
保存後の応答を試験で差し替え、結果が分からない時の同じ操作での確かめ直しを通す。候補の中身を直す前に答えや決めた日が
使われなくなると示し、直した後は前の答えを数えないことも確かめる。英語は 1280 × 800 の画面でも一つの道筋を通す。
架空の家の時間を変更して子の居場所の時間が二つに分かれる日を作り、選んで頼んだ後の「断られたら？」にも、
残る時間と手配の分が日英で示されることを確かめる。
家の人の手が離せない時間を足す前に候補日の重なりを見て、決めた日と「きょう」の表示、外した後の表示を携帯幅で通す。
英語のデスクトップ幅でも、記録前の変化と記録後の重なりを確かめる。
日常の `pnpm check` には含めない。ブラウザは初回だけ用意する。

「すること」に Claude の架空の案を表示し、分からない欄を選び、見てから保存する道筋も通す。
この道筋では案の API 応答をブラウザの中で作るため、読み取りの口やモデルの応答は確かめていない。

```sh
PLAYWRIGHT_BROWSERS_PATH=.local/e2e-browsers pnpm exec playwright install chromium
pnpm e2e
```

このリポジトリの外にブラウザが既にある場合、試験用の独立したプロセスとしてその実行ファイルも使える。
利用中のブラウザやタブには接続しない。

```sh
MANIAU_E2E_BROWSER=/usr/bin/google-chrome pnpm e2e
```

API は 18797、画面は 15183、読み取り先の試験用入口は 18798 を使う。使用中なら既存のサーバーを
使わず終了する。親の環境と `.env` は引き継がない。画面には読み取り欄を出すが、SDK の接続先は
失敗を返す手元の入口に固定し、主線の途中で呼ばれないことも確かめる。読み取りの精度はこの試験では測らない。

画像と失敗時の控えは `.local/e2e-results/` に置く（Git には入れない）。各画像はその時の画面の範囲で、
撮っただけでは読みやすさの判定にならない。実機の iPhone での確認も別に必要。
