# デモの家族（架空）

デモと試験に使う、架空の家族とお知らせ。人・学校・学童の名前と決まり、お知らせの文、勤務先は架空である。駅と線路は実在の物を使う（豊洲の辺り、東京都江東区）。日付は 2026年11〜12月（曜日と祝日は内閣府のデータで確かめた）。

- 実在の学校・学童・人と取り違えないよう、名前に「（架空）」を付ける。
- 店は、家族が登録した物として、名前を一般的な言い方にし、営業時間は家族の申告（`source: family`）とする。地図のデータ（Google）はここに入れない（条款により、保存してよいのは place ID と調べた時刻だけ）。実際の店と営業時間は、使う時に地図で調べ、「要確認」と示す。
- 決まり（学童の届けの締切、有休の申請、祖母に頼む期限）は、この家族が登録した物で、実在の学童や勤務先の決まりを表さない。
- やり方（`ways`。通用の「すること」を満たす手立て）は、この家族が確かめた物として入れてある：病児保育に預ける、祖母に来てもらう、区のホームページで申し込む、地区センターの窓口で申し込む（地区センターは架空。窓口は平日 9:00〜17:00 で、家族のふだんの予定にそこにいる時間は無い）。実在の区の手続きを表さない。

| ファイル                           | 中身                                             |
| ---------------------------------- | ------------------------------------------------ |
| `household.json`                   | 家族、場所、ふだんの週、取れる手の決まり、やり方 |
| `notices/2026-11-25-happyokai.txt` | 11/25(水) に届く学習発表会のお知らせ             |
| `notices/2026-12-04-enki.txt`      | 12/4(金) の夕方に届く延期の連絡                  |

## 記録した周りの調べ（実在の頁）

`recorded/survey.json` は、ほかと違い、架空ではない。2026-11-05 に、デモの家の地域（江東区・豊洲）の周りを Claude が一度だけ本物のウェブで調べ、コードが照らした結果で、実在の施設の名前と頁の URL・題を含む。頁の本文と、引用として抜き出した頁の文は持たない（引用は照らす時にだけ使った）。出典は `THIRD_PARTY.md` に書く。

## 例 2 で貼るお知らせ（架空）

学校の行事でない家庭の用事として、「撮る」→「お知らせを入れる」に貼って読み取る（Claude を一回呼ぶ）。

```text
来年度も学童クラブを利用する家庭は、12月4日（金）までに継続の申し込みをしてください。申し込みは、地区センターの窓口（平日 9:00〜17:00）か、区のホームページの申し込みフォームでできます。
```

読み取りを確かめ、「来年度も学童クラブを利用するか」に答え、使うやり方に二つを選ぶと、窓口の手は「この手には、ふだんの予定に置ける時間が無い手順があります」と出て、区のホームページだけを勧める（`apps/server/test/need-by-ways.test.ts` が、手で書いた読み取りで同じ道を確かめる）。
