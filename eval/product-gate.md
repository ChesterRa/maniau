# G1：作り手と確かめる 10 分

目的は、自分の家の実際の段取りにこの製品が合うか、作り手自身が判断すること。完成前は紙や試作を使ってよい。机上で「減りそう」と答えたことと、実際に使って減ったことを分ける。

## 始める前

- 作り手だけが、直近の出来事を 2〜3 件選ぶ。振替休業日、平日の行事、急な変更など、種類が違えばなおよい。第三者への聞き取りは行わない。
- 本物のお知らせ、住所、学校・園名、家族名、勤務、正確な日付などは、作り手の手元だけに置く。口頭で中身を共有せず、API やこのリポジトリにも入れない。記録には下の集計だけを使う。
- 紙または試作を用意する。各出来事について「行事・変更」「選択肢と最後に決める時」「次の一手」「担当の提案と引き受け」「外部の返事待ち」「変更で不要になる物・相手への連絡」を並べる。事実と推定を区別する。

## 当日の進め方

| 時間 | 作り手にしてもらうこと | 確かめること |
|---|---|---|
| 0:00〜1:00 | 2〜3 件を手元で選ぶ | 私たちが例を誘導していないか |
| 1:00〜5:00 | それぞれを紙または試作の流れに当てはめる | 本当に必要だった決定、最後に選べた時、制約、選ばなかった案が表せるか |
| 5:00〜7:00 | 一件で、別の人に頼み、返事を待つ流れをたどる | 誰が何を引き受けるか、提案・引き受け・返事待ち・確定が区別されるか |
| 7:00〜8:00 | 一件で、元の予定が変わった場合を考える | 外す準備、残す準備、連絡すべき相手が分かるか |
| 8:00〜10:00 | 入力と確認に見合うか、使いたいかを答える | 何が足りないか、どの通知なら要るか、自分で追う回数が減りそうか。帰り道の店と時刻を提案するため、家・学校や学童・職場・通勤の登録に仮に3分かかるとして、その価値があるか。入力したくない場所があれば、種類だけ答える。所要時間は未実測 |

問いは中立にする。「役に立ちますか」だけで終えず、「次に何をするか分かりますか」「ここを相手に任せるには何が足りませんか」「どこで自分が確認・追いかける必要がありますか」と聞く。実際の使用前は追跡回数の変化を予測として記す。実際に使った場合も、観察期間と測り方を添え、過去の記憶との比較を厳密な測定と言わない。

## 個人情報を含まない記録

各行は件数、選択肢、または内容を特定できない短い理由のみ。事例を再識別できる組合せは記録しない。

| 項目 | 記録 |
|---|---|
| 形式 | 紙／試作／実使用 |
| 当てはめた件数 | 件 |
| 必要な決定と期限を表せた件数 | 件／上記の件数 |
| 人に任せる流れが十分だった件数 | 件／上記の件数 |
| 返事待ち・変更が正しく表せた件数 | 件／該当する件数 |
| 自分が追う回数 | 減りそう／変わらなそう／増えそう／判断できない。実測なら回数と期間を別記 |
| 入力・確認の手間 | 見合う／条件付き／見合わない／判断できない |
| 場所と通勤の入力 | 見合う／条件付き／見合わない／判断できない。入力したくない場所は種類だけ |
| 最も困った欠け | 一般化した短い説明のみ |
| 判断 | このまま続ける／画面と流れを直す／扱う出来事の種類を変える |

欠けた情報、引き受ける相手の反応、通知や結果が実際に使われたかは未確認のままにできる。紙で検討しただけなら、そのことを判断の根拠に明記する。
