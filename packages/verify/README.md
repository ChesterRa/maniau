# 計画の検証

`@maniau/core` の型・時間のデータと、事象の列を入力にする。計画エンジンは読み込まない。JSON から読み直した入力も、入口で型を検査する。

```ts
import { verifyPlan } from '@maniau/verify';

const result = verifyPlan({ household, plan, events });
```

`status` は次の三つで、`issues` の `code`・`subject`・`detail` は個別の理由を示す。

| 状態           | 意味                                                   |
| -------------- | ------------------------------------------------------ |
| `pass`         | この検証で該当した条件を満たし、未確認の条件も無い     |
| `violation`    | 少なくとも一つ、与えられた条件との矛盾がある           |
| `undetermined` | 違反は見つからないが、確認に必要な情報や証明が足りない |

違反があれば未確認の点も `issues` に残し、全体の状態は `violation` とする。`undetermined` を `pass` と同じ意味にはしない。全体の状態だけでなく個々の理由を呼び出し側で扱う。

## 確かめること

- 家庭・計画・事象の型と家庭 ID、事象の順序、本命と予備の選択、本人だけの引き受け操作。
- お知らせの文の分類、書かれた曜日と日付、条件の式、回答と変更による元の事項の適用。
- 生きている作業・手配・要件から元の根拠へたどれるか。推定を確認前に必須と扱っていないか。
- 作業の所要時間、担当の区間、場所、営業時間、移動を含めた人の占有、重なり、先後、家庭の手順と締切。比較中の候補は、本命や予備と同時に実行する作業として数えない。
- 帰宅が遅れる寄り道では、別の大人の在宅と同時刻の作業を照らす。到着の時刻を遅らせる確認は、担当本人が最後の提案で見た時刻と、今の作業・到家時刻が一致する場合に限る。
- 依頼ごとの送信・返事・取消しと本命・予備の選択を事象から照合する。送信時の控えがあれば、今の作業ではなく控えの相手・種類・根拠と照らす。確かな一対一の訂正は、元の根拠から置き換え先へたどる。不要と確かめられた依頼の取消し、まだ必要と確かめられた依頼への誤った取消しを調べる。必要性が不明な時は、計画の `live` だけから取消しを要求しない。取消しを送った記録は、相手の受理・既読の証明ではない。
- 決め時を現在時刻と照らし、期限を過ぎた未選択の案を推薦していないか、断られた案の代わりがあるか、取れるか未判定の案を残したまま「不可能」としていないかを確かめる。

## 確かめられないこと

原文からモデルが事項を読み落としたか、文を「関係なし」に誤って分けたか、すべての要件が導かれたかは保証できない。文の分類の検査は、その一部の防線である。入力が正しいか、実際の営業時間・在庫・経路・到着時刻が正しいかは別に確かめる。

駅からの徒歩が目安なら、実際の道のりは未確認とする。地図の詳細な根拠を受け取る型はまだ無いため、`maps` も未確認とする。営業時間に必要な期間や出典が足りない時、事象が欠けた時、昔の作業時点の家庭の条件を確認できない時も未判定にする。

担当本人が確認したこととして照らせるのは、記録された開始・終了・遅れた到家の時刻だけである。同じ時刻でも、店や道のりの変更を確認した証明にはならない。条件の式は共有された子の結果を再利用し、各通知の読み取りが64節点または5000辺を超える場合は、その式を未判定とする。

送信前の条件と現在の条件の比較は、一つの未定値と比較する値が変わった場合など、一部しか確かめられない。節点 ID が同じでも意味が同じとは限らず、違っても意味が違うとは限らない。複雑な条件や、送信前の事象が足りない場合は未判定とする。置き換えが競合・循環する場合や、条件付きの回答と取消しが複雑に影響し合う場合も、保守的に未判定を残す。

開始操作を記録する事象はまだ無い。「済んだ」「送った」が無いことは、作業を実際には始めていない証明にならない。決め時を過ぎても進捗の記録がない案は、進捗を確認できないと報告する。

決め時が可能な時刻かどうかの条件は一部照合するが、それが**最も遅い可能な時刻**か、不可能とされた問題に本当に解が無いかは、独立に探索していない。認証済みの本人から操作が来たかはサーバー側の責務であり、ここでは受け取った事象の担当と操作人を照らす。
