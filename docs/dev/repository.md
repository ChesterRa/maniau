# リポジトリに入れる物・入れない物

このリポジトリは公開している。一度 push した物は、後で消しても、複製やキャッシュに残る。入れない物は、コミットの前に止める。迷ったら入れずに、作り手に聞く。

## 入れる物

| 物 | 置き場所 | 条件・理由 |
|---|---|---|
| 製品のコード（読み取り、制約のモデルと求解、検証器、MCPのサーバー、画面）と試験 | 作る時に決める | 動く物と、その確かめ方を誰でも見られるように |
| プロンプト | コードと同じ場所 | 製品の一部として版を付ける |
| 試験のために録った Claude の応答 | 試験の fixtures | 架空の材料から得た物だけ |
| 評価の仕組み：場面、正解、比べる相手のプロンプト、採点 | `eval/` | 比べた数字を、誰でも確かめ直せるように |
| 文書や動画で引く評価の結果 | `eval/results/` | モデル・日時・プロンプトの版・回数・費用を添える |
| 架空の家族の材料（おたより、予定、勤務） | `data/demo/` | 自分たちで作った物だけ（§3） |
| 計画、調査、判断の記録、評価の報告、動画の台本 | `docs/` | 何を考え、何を確かめ、何を変えたかを残す |
| Claude の使い方の記録 | `docs/dev/claude-usage.md` | 目的ごとに選んだ機能と、その効果 |
| Claude Code の共有の設定：`.claude/settings.json`、`.claude/hooks/`、`.claude/skills/`、`.claude/agents/`、`.mcp.json` | `.claude/` と直下 | 鍵と手元の絶対パスを書かない |
| 依存の固定（lockファイル）、`.env.example`、検査（`scripts/git-hooks/`） | 直下と `scripts/` | 同じ環境と同じ検査を作り直せるように |
| 利用条件が許す第三者の物（データ、フォント、アイコン等） | 使う場所 | 出典と条件を `THIRD_PARTY.md` に書く（§3） |
| 小さな画面の写真と図 | `docs/` | 架空の家族だけが写る物（§2） |

## 入れない物

| 物 | 置き場所 | 理由 |
|---|---|---|
| 鍵：APIの鍵、各種のトークン、ハッカソンの引き換えコード | `.env`（Gitの対象外） | 漏れると悪用される |
| 実在の家族の材料：本物のおたより・写真・予定・勤務、子どもの名前、学校・園の名前 | リポジトリの外（`~/dev/maniau-private/`） | 個人情報。名前を消しても、日付と行事から学校や家族が分かり得る |
| 聞き取り（期間の後に行う予定）の録音・メモ、同意書 | 同上 | 同上。同意を得た短い言葉と、同意の範囲の集計の数字だけを文書に書く |
| 実在の材料を使った評価の出力 | 同上 | 個人情報を含む |
| 公開されている実在のおたより（学校のサイトの PDF 等） | 入れない | 学校の著作物で、人名を含み得る。読み取りの確かめに使う時は手元だけで |
| エージェントへの指示（`AGENTS.md`、それを読み込む `CLAUDE.md`） | 手元（Gitの対象外） | 作り手の作業の決まりで、手元だけで使う |
| 主催者の参加者向けの資料（キックオフの記録等）と、手元の作業の控え（引き継ぎ等） | `.local/`（Gitの対象外） | 主催者の資料は公開を前提にしていない。作業の控えのうち、残す価値のある決定と結果は `docs/` に書く |
| エージェントとの会話の記録、作業の台帳 | 各道具の保存場所 | 作り手との会話を含む。使い方は `docs/dev/claude-usage.md` にまとめる |
| 評価の生の出力 | `eval/runs/`（Gitの対象外） | 量が多い。引く物だけを `eval/results/` に移す |
| 動画・音声の素材 | リポジトリの外 | 大きい。完成した動画は YouTube 等に置き、リンクだけ書く |
| 依存・ビルドの出力・キャッシュ・記録（log） | （Gitの対象外） | 作り直せる |
| 使用権のない物：利用条件が分からない、または許さないコード・データ・画像・フォント、論文の本文 | 入れない | 使う権利がない。使用権のない物は、ハッカソンで失格になる |
| Claude Code の個人の設定：`.claude/settings.local.json`、`CLAUDE.local.md` | （Gitの対象外） | 個人の環境 |

## 1. 大きさ

- 一つのファイルは 5MB まで。リポジトリ全体も軽く保つ（目安 50MB）。
- 大きな物は、作り直せる手順か、外の置き場所へのリンクにする。

## 2. 公開する物に書かないこと

- 作り手や家族の個人情報（名前・メール・住所・勤務先）。
- 手元の絶対パス、作り手の他のプロジェクトや取引先の名前。
- 画面の写真・動画のコマ：架空の家族だけを写す。ブラウザのタブ・ブックマーク・通知・他の窓・鍵が写らないようにする。
- 写真は、撮った場所などの情報（EXIF）を消してから入れる。

## 3. 第三者の物と、生成した物

- 依存（ライブラリ）は、利用条件が MIT と両立する物を選び、lock ファイルで固定する。
- フォント・アイコン・画像・データは、利用条件を確かめてから使い、出典と条件を `THIRD_PARTY.md` に書く。条件が分からない物は使わない。
- 生成AIで作った画像・おたよりは、作り方（道具と指示）を同じ場所に残す。実在の学校名・人名・ロゴを入れない。
- 架空の家族・学校の名前は、実在の人や学校と取り違えない名前にする。

## 4. 守り方

- `.gitignore` が、置き場所の決まった物を除く。
- コミットの前の検査（`scripts/git-hooks/pre-commit`）が、次を止める。
  - 作者のメールが、GitHub の noreply のアドレスでない時（個人のメールを公開の履歴に残さない）
  - 鍵の形をした文字列（Anthropic、GitHub、AWS、Google、Slack の鍵と、秘密鍵）
  - `.env` 等、`.local/`・`private/` の物、`AGENTS.md`・`CLAUDE.md`、Claude Code の個人の設定
  - 動画・音声・端末の写真（mp4、mov、m4a、wav、mp3、heic。大文字も）
  - データベース（`*.db`、`*.sqlite` 等。実在の家族の事象が入り得る）
  - 実在の家族の材料の置き場所（既定は `~/dev/maniau-private/`。環境変数 `MANIAU_PRIVATE_DIR` で変えられる）にある物と、中身が同じ物
  - 5MB を超える物
- `scripts/git-hooks/commit-msg` が、Claude Code の中で作ったコミットに `Co-Authored-By: Claude <noreply@anthropic.com>` を付ける（このリポジトリだけの決まり）。`.claude/settings.json` の attribution と同じ行で、付け忘れを防ぐ。手で作ったコミットには付けない。
- Claude Code のフック（`.claude/hooks/guard-paths.py`）が、ホームの下と `/mnt/` を指すパスへの道具の使用を止める（このリポジトリ、材料の置き場所、このリポジトリ用の記憶を除く）。見るのは道具の引数と、コマンドに書かれたパスだけで、書き方によっては見抜けない。網の一つであり、守りの全部ではない。Claude Code は、このリポジトリの直下で起動する（サブディレクトリで起動すると、このフックは読み込まれない）。
- 検査とフックの試験は `tests/hooks/` にある（`python3 -m unittest discover -s tests/hooks`）。
- clone した後に、一度だけ `git config core.hooksPath scripts/git-hooks` を実行する。
- `--no-verify` で検査を飛ばさない。検査が見るのは、作者のメール、鍵の形、置き場所、種類、大きさ、材料の写しだけである。個人情報や使用権は、コミットする人が確かめる。
- GitHub の設定で、個人のメールを含む push を止める（Settings → Emails → Block command line pushes that expose my email）。
- push は少なくとも一日一回。期間中の進み具合が履歴に残るように。

## 5. 誤って push した時

- 鍵：すぐに無効にして作り直す。履歴を書き換えても、すでに複製されている。
- 個人情報・使用権のない物：すぐに作業を止めて作り手に知らせ、履歴から消す。GitHub にも、キャッシュの削除を頼む。
