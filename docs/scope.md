# 詳しい動きと制限

[English](scope.en.md) ・ [README](../README.md)

README の「できること」の詳しい動き、自分の文で試す時に Claude に送る物、今の対応範囲と制限です。

## 詳しい動き

- **お知らせを読む**：貼った文や、携帯のキーボードで音声入力した文、プリントの写真・PDF から書き起こして確かめた文を Claude が読み、行事・持ち物・提出物・日課の変更などを取り出します。取り出した事項は元の文と結び付けて残し、お知らせの画面では、事項のある文と確かめてほしい文に印を付けます。
- **決め時を示す**：お知らせの締切、家族が登録した決まり（学童の届け、休みの申請、祖父母に頼むなら何日前か）、ふだんの週（勤務・通勤・お迎えの担当）から、案ごとに「いつまでに決めれば間に合うか」の目安と次の作業を出します。買い物は、帰り道に寄れる店と営業時間から、買える時を示します。使う日の書かれた持ち物は、家にあると答えた物と買い終えた物を、使う日の前の日から「きょう」に並べます。無かったと分かれば、使う日が終わるまでは、そこで答え直せます（用意の締切の前なら買う手配を出し、過ぎていれば無いことを二人に示します）。登録した手立てでは間に合う方法が見つからない時は、そう示します（ほかの手は家族が考えます）。
- **選ぶ**：手配ごとに、選べる手と、それぞれの手が消えるまでの時間を並べ、決まりで選んだお勧め（休み・人に頼むこと・費用・増える作業を目安の重みで合わせて、負担が一番軽い手）とその理由を示します。手ごとに「選んだら」何が起きるか（最初の作業と担当、返事を待つこと、取り消しを伝える相手、時刻の動くほかの作業）を、書き込まずに同じ計算をして示し、検証器で新しい違反が見つかればそれも示します。手の決め時は大人の誰かが間に合う最後なので、自分の時間にもう置けない手は、置ける大人に作業を提案する形で示し、自分でするなら早く始める必要がある時は、後まで間に合う人と時刻を添えます。見せた後に中身（日・作業・担当・取り消し・時刻の動く作業）が変わっていたら、選ぶ前に見せ直します。家族が進める手（本命・予備）どうしは、同じ大人の同じ時間に重ならないように一緒に置き、引き受けた時刻はなるべく動かしません。済ませた手順と、本命が決まってもう進めない予備は、時間を取りません（済ませた時刻は記録に無いので、計画の時刻を済ませた時として残しません）。重ならない時刻を見つけられなかった手の作業は、重ねて置かず、時刻を決めずに残して、手・する人・時間を見直すよう示します。選んだ後も替えられます。
- **誰が持つかをはっきりさせる**：作業を大人の一人に提案し、本人が引き受けたか断ったかを記録します。祖父母や学童への頼み事は、返事待ちと確定を分けて扱います。返事待ちの頼み事では「断られたら？」で、断られたと仮に置いた同じ計算（予備に進むか、選び直しになるならお勧めの手と、いつまでに返事をもらえば間に合うか、残る手の決め時）を、何も記録せずに見られます。進めている案で担当のいない作業は、大人の全員の画面に出ます。お知らせの提出物（「○日までに提出」）も、締切までの作業として、だれかが持つまで大人の全員の画面に出します。どちらも、締切（案の作業なら案の決め時）のおよそ一日前になってもだれも持っていなければ、大人のそれぞれに知らせを送ります（受け取るには、各自が知らせをオンにしておく必要があります）。
- **変更に合わせる**：延期などで予定が変わると、要らなくなった準備を外し、すでに頼んだ相手への取り消しの連絡を下書きします。読み取った日を直した時は、前の日に頼んだ返事で新しい日を決めず、新しい日の分を頼み直せます（頼み直した後の前の日の分は、取り消しを伝える作業にします）。頼んだ後に前提が変わり、頼んだ相手に確かめる必要が出た時は、確かめるまで予備をたたみません。
- **「すること」として扱う**：家族の言ったこと（「あす8時から18時まで、だれかが家で見る」）や、お知らせが求める出席・申し込みを、子の居場所と同じ流れ（やり方を選ぶ・作業・引き受け・頼み事・取り消し）で扱います。お知らせから読んだ物は、家族が元の文と並べて確かめるまで計画に入れません。進め方は、家族が登録したやり方から家族が選びます。Claude にやり方の案を出してもらうこともできます（推定です。家族が表で直して保存するまで、やり方になりません）。
- **一言で伝える**：「おばあちゃん、12/7は大丈夫だって」のような一言から、どの頼み事・作業のことかを探し、記録の案を出します。「おばあちゃんがダメだったら？」のような仮の話なら、何も記録せず、「断られたら？」の計算へ案内します。「12/7 は休めたら？」「水曜は19時まで会議」のような大人の一日の話なら、だれ・どの日・どう変わるかを直せる欄で見せ、何も記録せずに、同じ計算で何が変わるかを示します（言われていない前提は「仮に置いた前提」と分けて書き、記録は家族が「この日を記録する」を押した時だけ。「うちのこと」からも足せます）。押すまで記録しません（デモ）。
- **周りの資源（始まり）**：「うち」の「周りの資源」に、家の周りの施設・サービスと、使う前に一度だけ済ませておく事（事前の登録など）を持ちます。済んでいるかは家族が確かめて入れ、済んだと確かめていない事のある手はお勧めせず、案の札に「前もって：…」と出します（家族は選べます）。家族が「使わない」とした所を使う手もお勧めせず、ほかの手を比べてお勧めします。デモの病児保育室とその事前登録は、デモのための架空の決まりです。
- **周りを調べる**：「周りの資源」の「周りを調べる」で、家の地域（区と駅の粒度）の病児保育・一時保育・ファミリー・サポートを、Claude がウェブで探して頁を読み、候補を出します。出すのは、読んだ頁の本文に引用がそのままあった物だけで（コードで確かめます）、頁が公式か・中身が今も正しいかは、リンク先で確かめてください。事前の登録が要るかは Claude の読みとして原文と一緒に出し、家族が「要る・同じ登録・要らない・まだ分からない」を選びます。家の情報に入るのは、家族が「この家の候補にする」で入れた物だけです。入れた所に頼むやり方は、今のやり方を写して作ります（前のやり方は替えません。前の所の時間・費用・期限は写さず、この所の頁で確かめて入れます。事前の登録は、その表で選び直します）。デモでは、2026-11-05 に江東区・豊洲を一度だけ本物で調べて記録した結果を出し、「Claude にいま調べ直してもらう」は一つのデモで 3 回までです。家族の家庭では、まだ使えません。定期の見直しは、まだありません。

## 自分の文で試す

サーバーに `ANTHROPIC_API_KEY` を設定すると（環境変数か、リポジトリ直下の `.env`）、「お知らせ」画面に文を入れる欄が出ます。貼った文や、携帯のキーボードで音声入力した文を Claude API で読み取り、計画にできる事項を計画に入れます。読み取った事項のある文と確かめてほしい文には、計画に入れたか、よていに出すか、読んだだけ（まだ知らせない）か、確かめてほしいかの印を付けます。

プリントや連絡帳の写真・PDF も入れられます。Claude が書かれた文字を読む順にそのまま書き起こして欄に入れるので、写真と見比べて違う所を直してから読み取ります。写真はサーバーにも記録にも残さず、読み取った出典には写真から書き起こした文だと示します。一度に送れるのは、写真1枚か、数ページ（5ページほど・4MB）までの PDF です。書き起こす前に、Anthropic の数える口（無料）で入力の量を見積もり、多すぎる時は書き起こしを呼ばずに断ります（見積もりのためにも写真・PDF を送るので、この時も一回と数えます）。

同じ設定で、「きょう」の画面の上に「ひとこと」の欄が出ます。返事が来た・頼んだ・済んだ・できなくなった・持ち物が家にある（ない）等を一言で伝えると、どの頼み事・作業・問いのことかを探して記録の案を出し、押すと記録します（その種類の相手がほかにもある時は、記録せず「きょう」の札へ案内します。下の「現在の対応範囲と制限」）。見せた後に、もう一人が記録した等で対象が変わっていれば、記録せずに見せ直します。計画について聞くと（「12/5の持ち物は？」）、当てはまる事項と状態を並べます。「おばあちゃんがダメだったら？」のように仮の話をすると、記録の案は出さず、今返事を待っている頼み事を見せ、押すと「断られたら？」と同じ計算を見せます（何も記録しません）。Claude が、本当の返事か仮の話か決められない、または一つの一言に両方が混ざっていると読んだ時は、どちらの案も出さず、分けて伝えてもらいます（読み違いはあり得るので、出た候補は押す前に確かめてください）。

同じ設定で、「すること」の画面から Claude にやり方の案を出してもらえます（「Claude に案を出してもらう」）。考え（「祖母に頼めるかも」など）を添えると、家の大人・頼める人・場所・今のやり方を組み合わせた案を3つまで出し、今のやり方で足りる時はそれを示します。案は推定で、出しても何も変わりません。案を「やり方を足す」の表に入れ、直して、変わることを見てから保存します。Claude に分からなかった欄（だれがする・頼む相手・受け持つか等）は、家族が選ぶまで保存できません。値段・相手の返事の早さ・締切の決まり・受け持てる時間は、Claude の案に欄が無く、家族が入れます。

地図の鍵もあるサーバーでは、店を探す時に、Claude に探す言葉の案を出してもらえます（「探す言葉の案を Claude に聞く」）。案は推定で、押すまで聞かず、出ても何も探しません。家族が確かめて（要れば直して）「探す」を押した時だけ Google で探します。

入れた文と、そのデモですでに記録した事項（家族が言ったことを含む）と未定の問いは Anthropic に送られます。写真・PDF は、入力の量の見積もりと書き起こしのために送られます。一言では、一言と、そのデモの家族・頼める人の名前（架空）、今の事項・作業・頼み事（相手や場所を含む）が送られます。店を探す言葉の案では、品物の名前だけが送られます。やり方の案では、その「すること」（何を・いつ・場所・元の文）と考えとそれを書いた大人、家の大人・頼める人・場所の名前、今のやり方の名前と手順の名前が送られます（家の情報のほかの欄〔ふだんの週・子・営業時間など〕は送りません。送る文と名前の中に書いてある事は、住所や予定でも、書いたまま送られます）。架空の文か、人や場所の分かる所を消した文・写真で試してください。読み取りは、一つのデモでお知らせ5回・写真の書き起こし5回・一言20回・やり方の案5回・店を探す言葉の案10回、サーバーのプロセスごとに一日（UTC）合わせて100回、同時に2件までです。家庭モードのサーバーでは、デモの読み取りも書き起こしも一言もやり方の案も店を探す言葉の案も使えません。家庭モードの試しの家庭でも、同じ物（その家庭の物）が Anthropic に送られます。回数は、家庭ごとに一日（UTC）100回（お知らせ・一言・やり方の案を合わせて）、同時に1件までです。

## 現在の対応範囲と制限

- 文と写真の取り込みは、API キーを設定したデモで使えます。家庭モードでは、試しの家庭（データベースで test と印を付けた、架空の家族の家庭）だけ、文と一言を読めます（写真はまだです。実在の家族の文は、まだ入れません）。写真の書き起こしは、合成した印刷の連絡帳の写真で確かめただけで、手書きや実際のプリントの写真では、まだ確かめていません。
- 家庭モード（Cloudflare Access による身元の確認、Postgres への記録、Web Push の通知）は実装済みです。iPhone のホーム画面と組み合わせた実機での確認は、これから行います。通知の配信事業者が受け付けたことは、本人に届いた・読まれた証拠ではありません。
- 実在の家族のデータは、認証・削除・通知などの安全性を実際の環境で確かめるまで入れないでください。条件は[地基の設計](design/02-foundation.md)にあります。
- 一言で記録できるのは、返事・頼んだ（出した）・済んだ・できなくなった・断る・取り消しを伝えた・未定の値への答え（持ち物が家にあるかを含む）です。担当を替えること、一度に二つ以上の記録は、まだ受け付けません。ふだんの週の変更は、一人の大人の一日だけ（一日休み・その時間は家・その時間は外出・仕事の終わり）を、記録せずに前提の画面へ案内します。ずっと続く変更、二人以上・二日以上の話、お迎え・送りだけの話、在宅勤務、日をまたぐ予定は、まだ受け付けません。仕事や通勤の途中で家に移る一日（職場との行き来の時間が分からない）と、お迎えのある日に仕事の終わりを変える一日（お迎えをどうするか分からない）は、計算せずに訳を示します。外出の行き先と行き来の時間は、外出の時間に含めて入れてもらいます。日は、一言の原文の言い方（今日・明日・明後日・12/7・12月7日・来週の月曜など）からコードが求めた日と、読んだ日が同じ時だけ入れます。ほかの言い方、一つの日に決まらない言い方（日曜に言う「来週の月曜」、金曜に言う「金曜」、英語の「next Friday」など）、食い違う時は、日を空けて画面で入れてもらいます。名前などの中の「今日」「明日」を日と読み違えることは、家の人の名前のほかは防げないので、前提の画面に一言の原文を並べて出します。一言の仮の話は、返事を待っている頼み事が断られた時と、大人の一日の変更だけを計算します（大人が休めなかったら・行事が延期になったら等は、まだ受け付けません）。まだ選んでいない案の作業（比べるための候補）と、まだだれも持っていない作業（提出物など）も、一言では記録しません（先に案を選ぶか、「きょう」でだれがやるかを決めます）。一言で記録するのは、その種類の相手がほかに無い時だけです（作業なら計画の作業が一つだけ、頼み事なら記録の先になりうる頼み事が一つだけ、答えなら一言で答えられる問いが一つだけ）。ほかにもあれば、題・名前・品名・日付がはっきり違っても、一言では記録せず、「きょう」の札から記録してもらいます（文や日付の書き方は、同じに見えて違う物を見分けられないので比べません）。デモでは、作業と答えは、いつも札からの記録になります。家庭モードの試しの家庭では、「すること」の頼み事の返事と、取り消しを伝えたことも、一言では記録しません（「きょう」の頼み事の札で、送った時の中身を見て記録します）。
- 宿題のうち家の人がすること（サイン、丸つけなど）と、家の人の当番は、作業にします。うちの番かは、対象の書き方（家の子の名前か、ほかの家の名指しだけか）と、同じお知らせの当番表から推し量ります。名字で書かれた行などでは誤ることがあるので、どの当番の札も「うちの番ではない」と言えば作業から外れ（もう一人が引き受けた当番は、その人が言います）、出典の画面の「うちの番です」で言い直せます。ほかの家の番と読んだ物も、「うちの番です」で作業にできます。この言明は、読み取りの推定を確かな物にはしません（推定の行は、まだ計画に入れません）。
- 時刻は、事項が指す文に書かれている物だけを使います。読み取った時刻がその文に見つからない時は、その時刻を使わず、文を確かめてほしいと示します（締切は、その日の朝8時を目安にして日だけを見せます。始まりを確かめられなかった当番は、時刻に置かず、その日の始まりを目安に早めに知らせます）。日だけで読んだ締切も、その文に時刻らしい書き方（時刻、朝・夕方・登校前など）があれば、読み落としかもしれないので確かめてほしいと示します。「あしたまでに」のような締切の日は、届いた日からコードが決め、読み取りと違えば食い違いとして示します。午前・午後も 24 時制の印も無い「9時」は、午前と午後のどちらの読みも受けます。読み取った時刻を画面から直せるのは、お知らせから読んだ「すること」だけです（下の「すること」）。ほかは、元の文を見て、家族が判断します。
- 習い事・クラブからのお知らせの行事は、家族の情報で子に送り迎えの決まり（送りと迎えのどちらが要るか）を入れた時だけ、送り・迎えの作業にします（決まりは、まだ画面から変えられません。デモでは陽菜に入れてあります）。子が二人以上の家庭では、どの子の行事か分からないので、まだ作りません。書かれた始まり・終わりの前後に、片道30分の往復を目安に置きます（道のりは確かめていません。地図を使うのは帰り道の買い物だけです）。時刻の書かれていない方は、その日の作業にします。終わりが始まり以前の時と、元の文に「翌日」などとある時は、12時間までなら次の日の迎えにします。それでも迎えの日を決められない時（終わりだけで始まりが書かれていない時、終わりの時刻を読み取れなかった時など）は、行事の日を迎えの日として見せず、日時を元の文で確かめてもらいます（その迎えは知らせません）。札の「今回は要らない」で外し（もう一人が引き受けた物は、その人が外します）、出典の画面で言い直せます。送り迎えが勤務と重なる時の手配（祖母に頼むなど）は、まだ作りません。
- 引き受けた作業が、後のお知らせの取り消しや条件の変化、別の手を選んだことで要らなくなった時は、持った人の「きょう」の一番上に出し、動き始める時の前（始まった後なら終わるまで）に知らせます。引き受けた後に元のお知らせを読み直した時（元の事項が見つからない・別の物になった時を含む）、元のお知らせを消した時、家族の情報が変わって作らなくなった時は、要らないとは言わず、まだ要るか確かめてと出します。「分かりました」で引き受けを外します。その前にまた要るようになった時は、もう一度引き受けるかを聞き直します。通知が届いた・読まれたことは確かめられません。
- 「うちのこと」で、計算に使っている家族と暮らしの情報（人・ふだんの一週間・場所と店・取れる手）を見られます。直せるのは、今は、ふだんの一週間の時刻と過ごし方、店の営業時間、取れる手の締切の決まりです。保存の前に、同じ計算で「この変更で計画の何が変わるか」（子の居場所の手配が要る時間、手の決め時、作業の時刻や担当や行く店、引き受け直しが要る物など）を見せ、確かめきれない点は「問題なし」と言わずにそう書きます。
- お知らせが家族に決めさせる事（「参加される方は」「出席の場合は」など）は、答えで要る物が変わる時だけ「家族で決めること」として聞き、どちらを選ぶと何が要るか（期限つき）を並べます。決めるまで、それで要る作業は「だれがやるか」に出さず、その持ち物が家にあるかも聞きません。知らせは、要る物の最も早い期限の26時間前からです。答えた後に、読み直しや直しで問いや事項の中身が替われば、前の答えを添えて聞き直します。ほかの事項の作用（取り消しなど）を通じてだけ効く物は、まだ問いにしません（作業は条件しだいのまま見せます）。
- 「すること」：家族の言ったこと（「あす8時から18時まで、だれかが家で見る」）と、お知らせが家の人に求める行動（「各家庭から大人1名ご参加ください」「希望する家庭は窓口で申し込んでください」）を、同じ「すること」として扱います。形は、ある時間にだれかが要る（窓）と、いつまでに済ませる（締切）の二つです。家族の言ったことは、「きょう」の「することを足す」から原文と欄（何を・形・日・時刻・だれのため）で足し、保存の前に変わることを見ます。お知らせから読んだ物は、だれのためかを推さず、書かれていない時刻を作りません。締切の書き方（候補の日、打ち消した日、「登校前までに」など）は数え切れず、コードだけでは確かめ切れないので、家族が「きょう」の札で読み取りと元の文（お知らせの全文。読み取りが元にした文は太字）を見比べ、「合っている」（形がそろった時だけ）・「直す」・「読み取りが違う」・「うちには要らない」を選ぶまで、手配も作業も作りません（元の文と食い違うかもしれない読み取りは、そう添えて同じ札に出します）。札には、読み取った条件の式（「かつ」「または」「ではない」のまま）と、どの値に何と答えると読んだか、何（いつの物）を置き換える・取り消すと読んだかも見せ（別のお知らせの物には、そのお知らせを添えます）、見分けられる形で見せられない読み取りは確かめられないようにします（外すことはできます）。確かめる前に、それが前の物を置き換える・取り消すと読んだ時は、前の物を「しだい」として示し、確かめた時に効かせます。そのお知らせか、条件・答え・置き換えの先のお知らせを読み直した時は、もう一度確かめてもらいます。読み取った日時が過ぎていても、読み取った条件で今は要らなくても、確かめるまで札は消さず、そのことを添えます（読み違えた日や条件で、まだ要る物を隠さないため。もう要らなければ「うちには要らない」で外せます）。進め方は、家族が登録したやり方（手順・返事を待つ相手・受け持つ時間・代償）から家族が選び、選ぶまで作業を作りません。決まった場所でする手順（平日の昼だけ開く窓口など）を、ふだんの予定にその場所にいる時間が無いので置けない手は、決め時を出さず、過ぎたとも言わず、ふだんの予定に置ける時間が無い手順があると示して勧めません（デモの例：区への学童クラブの継続の申し込みでは、窓口ではなく区のホームページを勧めます）。窓の「すること」は、受け持つ家族の引き受けと外の相手の「はい」で覆えた時間だけを覆ったと言い、残る時間を時刻で示します（場所が書かれた物は、家族の受け持ちでは覆ったと言いません）。頼む文は相手が受け持つ手順だけに作り、場所への取り消しの文には何をを書きません（子の名前を含むことがあるため）。お知らせを入れた人には、読み取りから1時間たっても確かめていなければ、中身の無い知らせを一度出します（確かめが外れて札が戻れば、もう一度。夜は朝まで待ちます。締切に間に合うとは言いません）。本命を選ぶ時は決め時の26時間前から、やり方をまだ選んでいない時は日時（窓の始まり・締切）の26時間前から、受け持ちを確かめられない時間は窓の始まりの26時間前から終わりまで、二人に中身の無い知らせを出します（やり方を選ぶ前は、前もっての手順〔前の日の予約など〕が分からないので、それでは遅いこともあります）。やり方は、「うちのこと」か「すること」の画面で家族が足す・直す・やめます（保存の前に変わることを見ます。やめても、今選んである「すること」の選び・作業・頼み事は替えません）。ほかと同じ名前の人・場所は、足すことも、名前を変えて作ることもできません（どれのことか見分けられないため）。計画に入っている「すること」は、「中身を直す」「要らないにする」で直せます（直すと選んだやり方は選び直しになり、送った依頼は相手への確かめになります。要らないにすると、送った依頼には取り消しの連絡を出します）。Claude のやり方の案は、家族が表に写して直し、保存するまで何も変えません。案の名前・わけ・確かめてほしいことの文は、コードでは確かめられません（値段や時間が書かれていても、確かめた事実として扱わないでください）。Claude の案の確かめは、架空の例で数回行っただけです。
- 買う店の見分けは、今は服と食材だけです。ほかの持ち物（ハンカチ、絵の具など）は、要る日が分かれば家にあるかを聞き、無ければ「どの店で買えるか分かりません」と示します（買う時は出しません）。地図の鍵を設定したサーバーのデモでは、その札や買い物の札から、家の最寄りの駅の近くで店を探し、その品物を買う店として選べます（駅から歩いて15分まで、近い順に5つまで）。探す言葉は、家族が確かめた（要れば直した）物を、「探す」を押した時だけそのまま Google に送ります（人の名前や住所は入れないでください）。選んだ店は、何が変わるかを見てから保存し、place ID と家族の呼び名だけを家の情報に残します（Google の店の名前・住所は見せるだけです）。選び直すと、前に選んだ店からその品物を外します。
- 頼んだ後に、同じ日の中で時刻だけが変わった時は、頼んだ人に確かめるよう示すだけです（新しい時刻で頼み直したり、確かめたと記録したりする操作は、まだありません）。
- 一緒に置くのは、子の居場所の手配で家族が進める手（本命と、まだ進める予備）の、まだ済んでいない手順です。買い物の作業とは、まだ一緒に置きません。並べ方を全部試すのは四つの手までで、それより多い時は決まった順で一度だけ置きます。試すのは手ごとの並べ方で、別の手の手順を互い違いに置く置き方は探さないので、重ならない置き方があっても見つけられないことがあります（その時は、時刻を決めずに残して示します）。どの場合も、解が無い・一番良いとは言いません。
- 時刻や移動時間は目安です。地図の鍵を設定したサーバーのデモでは、帰り道の買い物に、要求ごとに Google マップで調べた駅から店までの歩く時間（行きと戻りを別々に）と店の営業時間を使います。照会の日から7日の内はその日の営業時間で確かめ、その外はふだんの営業時間で置きます（その日の臨時の休みは確かめていない目安と書きます。ふだんの営業時間でしか置けない時や、選んだ店の道のりを調べられない時は、買える時が過ぎたとは言わず、まだ判断できないと「きょう」に示します）。調べられない時は家庭の情報の目安（デモでは用意した例）を使い、そう分かるように書きます。Google から受け取った営業時間と道は、取っておかず、Claude にも送りません。引き受けた時に見た提案の控え（時刻・歩く時間・店の place ID）は、デモのサーバーのメモリにだけ残ります。家族の家庭（記録を保存する形）では、地図の値はまだ使いません。在庫、実際の営業、道の通りやすさ、到着時刻は保証しません。
