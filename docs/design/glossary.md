# 用語（日本語と英語）

画面、英語の README、コードの名前で、同じ言葉を使う。新しい言葉は、使う前にここへ足す。英語は短く平易にし、日本の制度の言葉は説明を添える。

## 状態と操作

| 日本語 | English | 意味・注意 | コードの名前 |
|---|---|---|---|
| 決め時 | decision deadline | ある案を選べる最後の時。過ぎるとその案は取れない。外の締切（期限）とは別の物で、締切・返事にかかる時間・営業時間・勤務から逆算する | `decisionDeadline` |
| 期限・締切 | deadline | 外で決まっている締切（届けの提出、申請） | `deadline` |
| 引き受ける | take on | 本人が担当を受けること。本人だけが押せる | `accept` |
| 引き受け待ち | waiting to be taken on | 提案されたが、本人がまだ受けていない | `proposed` |
| 返事待ち | awaiting a reply | 引き受けた後、外の相手（祖母、学童、勤務先）の返事・承認・受理を待っている。確定ではない | `awaitingReply` |
| 確定 | confirmed | 要る条件がそろった | `confirmed` |
| 済み | done | 本人が済んだと記録した | `done` |
| 断る | decline | 本人が引き受けない | `declined` |
| 断られた | turned down | 外の相手が「いいえ」と返した | `turnedDown` |
| できなくなった | can no longer do | 引き受けた後に、本人ができなくなった | `withdrawn` |
| 取り消し | cancellation | 前提が消えた準備を外すこと。頼んだ後なら、取り消しの連絡になる | `cancel` |
| 取り消しの連絡 | cancellation message | 頼んだ相手に「要らなくなった」と伝える文。下書きまで作り、送るのは家族 | `cancellationMessage` |
| その日だけの一日 | single-day change（画面：Just this day） | 大人のある日の区間の全部。その日はふだんの曜日の一日の代わりに使う。一日休み（Day off）・その時間は家（Home for a while）・その時間は外出（Out for a while）・仕事の終わり（Work end time）で作る | `routineExceptions` |
| 手が離せない時間 | busy time | 大人が、その時間は子を見守れない・ほかの作業ができない（家にいる時も）という記録。場所の区間（家・外出）は変えない。これからの作業の置き場・子を見られる大人・買い物の計算で除き、いつにするかの候補と重なれば一行で知らせる（答えは変えない） | `unavailable` |
| 仮に置いた前提 | assumptions we added | 家族が言っていないが、計算のために置いた前提（「家」の区間は子を見られる時間など）。言われた事と分けて見せ、直せるようにする | — |
| 周りの資源 | around us | 家の周りの施設・サービスの集まり。家族と AI が一緒に保つ（調べた候補は家族が入れる。家族の扱いは AI が替えない） | `resources` |
| 周りを調べる | look around us | Claude がウェブで家の地域の資源を探して頁を読み、候補を出す。出すのは、Claude が根拠に挙げた文（引用）が読んだ頁の本文にある物だけ（引用は照らすだけで、出さず残さない。まとめは頁の言葉や文を含むことがあるが、まとめが頁の文そのものか、根拠に挙げた文を含む時は、その文がそろえて 8 字以上なら出さない）。家族が「この家の候補にする」（Add as a candidate for us）で入れる | `survey` |
| いつもの店 | usual store | 周りの資源で家族が「いつも使う」とした店。買い物はこの店に置き、ほかの店が先に寄れても移さない。寄れる時が無ければ、ほかの店に黙って移さず、家族が選ぶ。扱い（いつも使う・候補・使わない）は家族だけが替える | `use: 'usual'`（店の資源） |
| やり方を写して、この所で使う | copy a way to use this place | 周りの資源の所に頼む・行くやり方を、今のやり方を写して作る。前のやり方は替えない。前の所の時間・費用・期限・返事までの時間は写さず、家族がこの所の頁で確かめて入れる。事前の登録は、写した表で選び直す | `copy`（画面の道） |
| 前もって済ませる事 | advance step（画面：Beforehand） | 使う前に一度だけ済ませておく事（事前の登録など）。済んだかは家族が確かめて入れる。調べた事からは「済んだ」にしない | `preparations`・`needsPreparation` |
| 頼み事 | request | 外の相手への依頼 | `request` |
| 下書き | draft | 送る前の文。まにあうは自分では送らない | `draft` |
| 予備の案 | backup option | 本命の返事を待つ間に押さえておく案。要らなくなれば取り消す | `backup` |
| 代案 | alternative | 同じ必要を満たす別の案 | `alternative` |
| 問い | question | 答えで計画が変わる時だけ出す | `question` |
| 知らせ | notification | 担当の本人の端末へ、要る時に送る通知（Web Push）。お知らせ（学校・園からの文）とも、画面の上に出る操作の結果の表示とも別の物 | `notify` |
| すること | to do | 家族の言ったことか、お知らせが家の人に求める行動（出席・参加・窓口での申し込み）。形は、ある時間にだれかが要る（窓）か、いつまでに済ませる（締切）。子の居場所・持ち物・提出物・当番など、専用の種類で扱う物は含めない | `need` |
| やり方 | way | 「すること」を進める家族の手立て（病児保育に預ける、祖母に来てもらう）。手順・返事を待つ相手・受け持つ時間・代償を持つ。家族が「うちのこと」か「すること」の画面で足す・直す・やめるデータ。Claude の案は、家族が表で直して保存するまでやり方にならない | `way` |
| やり方の案 | way idea | Claude が「すること」に出す推定のやり方（3 つまで）。押しても何も変わらず、家族が表に写して直し、保存するまでやり方にならない。値段・相手の返事の早さ・締切の決まり・受け持てる時間は含まない | `wayIdeas` |
| いつにするか | choosing the day | 窓の「すること」で、日を相手の答えで決める段。候補（2〜8）を出し、答えを集め、家族が一つに決める。決めるまで手配・作業を作らない | `when`（要件の欄） |
| 候補（日の） | candidate day | 「いつにするか」の日と時間の一つ。時刻を直すと代が進み、前の代への答えは当てない | `candidates`・`rev` |
| 答える人 | who answers | 候補に答える人：家の大人・頼める人と、名前だけの相手（家の外の人） | `needPeople`・`guest` |
| 要る人 | required | その人の「はい」が無ければ、その日にできない人（コーチなど） | `required` |
| 少なくとも何人 | at least how many | その日にする為に要る「はい」の人数 | `minCount` |
| 答えで変わりうる人 | answers that can change it | その人の答えしだいで、その日が答えの条件を満たすかが変わりうる人（たぶん・食い違い・まだの人）。一人の答えで決まるとは限らない。家族の画面だけに出す | `pivotal` |
| リンクから | the link | 一人ずつの答えるリンクから届いた答え。リンクを持つ人の答えで、本人の確かめではない（「本人が答えた」と言わない） | `source: 'link'` |
| 家族の記録 | a family record | 家の大人が、聞いた答えを記録した物。だれが記録したかを持つ | `source: 'family'` |
| 食い違い | conflicting | 同じ人の答えが、出所（自分の画面・リンクから・家族の記録）で違う。どれかにせず、まだとして数える | `conflict` |
| 受け持ちが要る | someone must cover the whole time | 窓の間ずっと、だれかが受け持つ必要がある「すること」。書かれていなければ要る。練習に行くなどは要らない | `holdNeeded` |
| まだ受け持ちを確かめられていない時間 | not yet confirmed as covered | 窓の「すること」で、受け持つ家族の引き受けと、外の相手の「はい」で覆えていない時間。だれもいないとは言わない | `notCovered` |
| まだ判断できない | can't tell yet | 計算が限られた時間で終わらない時、または候補が足りない時。「無理」とは言わない | `undetermined` |
| 要確認 | check needed | 地図や営業時間のデータが未来の日に当てはまるか分からない時、読み直しで前の事項が見つからない時、消した中身に頼っていた依頼など。消えた・取り消されたとは扱わない | `needsCheck` |

## 出典と事実

| 日本語 | English | 意味・注意 | コードの名前 |
|---|---|---|---|
| お知らせ・おたより | school notice | 学校・園・学童から届く文。原文はいつも残す | `notice` |
| 元の文・原文 | original text | 事実の出典の文。訳を出すなら訳と示す | `sourceSentence` |
| 記載 | stated | 元の文に書いてある事 | `stated` |
| 推定 | inferred | 書かれていない準備などを Claude が推定した事。家族が確かめるまで計画に入れない | `inferred` |
| 条件 | condition | 「5日に行った場合は」のように、事実が成り立つ条件 | `condition` |
| 条件しだい | depends on the notice | 条件の決まっていない事項。確かな予定として見せない。一つの未定の値で決まる時は「学習発表会の実施日が12/5（土）なら」のように書く（英語は if … is …）。二つ以上の値の組み合わせは言い換えない | `conditional` |
| 変更 | change | 前の事実を置き換えるお知らせ | `change` |
| 食い違い | conflicting | 書かれた曜日と日付が合わない等。家族が確かめるまで計画にも作用にも使わない | `conflicting` |
| 家族が確認 | confirmed by family | 推定・食い違い・読み違いを、家族が確かめた・直した事 | `confirmed` |
| 関係ない | not for us | うちの子に関係ない事項として家族が外した物。戻せる | `dismissed` |
| 取り下げ | withdraw | 家族が「このお知らせはもう当てはまらない」と言うこと。頼んだ後なら取り消しの連絡の流れになる | `sourceWithdrawn` |
| 削除 | delete | プライバシーのために中身を消すこと。取り下げとは別で、行事の中止とは推し量らない | `purge` |
| 書き起こし | transcription | 写真から文字に起こした文。写真と並べて確かめられる | `transcription` |
| 読み直し | re-read | 書き起こしを直した時などに、同じ出典をもう一度読むこと。前の事項との対応は家族とコードが決める | `reread` |

## 家族と暮らし

| 日本語 | English | 意味・注意 | コードの名前 |
|---|---|---|---|
| 家庭 | household | データを分ける単位 | `household` |
| 成員 | member | 大人・子・頼める人 | `member` |
| 頼める人 | helper | 祖父母など、家族が頼める外の人 | `helper` |
| 試用 | trial | 登録なしで、空から始めて試すこと（架空の内容だけ）。サーバーのメモリにだけ置き、12 時間使われなければ消える | `trial` |
| 見本の家族 | sample family | 試用で選べる、用意した架空の家族（予定・頼める人・取れる手がある） | `start: 'sample'` |
| 名前だけの家族 | your own family (names only) | 試用で、呼び名だけを入れて始める家族。予定や頼める人は、要る時に聞く | `start: 'own'` |
| ふだんの週 | usual week | 勤務・通勤・お迎えの担当の決まった形 | `routine` |
| お迎え | pickup | 学童・園への迎え | `pickup` |
| 帰り道 | way home | 職場から家まで、お迎えを含む | `commuteHome` |
| 寄り道 | detour | 帰り道に店へ寄ること。区間ごとに確かめる | `detour` |
| 学童 | after-school care (gakudō) | 放課後の預かり。決まりは場所ごとに違い、家族が登録する | `afterSchoolCare` |
| 一日利用 | full-day care | 学校が休みの日に、学童を朝から使うこと | `fullDayCare` |
| 振替休業日 | make-up school holiday | 土日の行事の代わりに学校が休む日。国の祝日ではなく、その学校だけ | `makeUpHoliday` |
| 有休 | paid leave | 年次有給休暇。申請の締切は勤務先の決まり | `paidLeave` |
| 時間休 | hourly leave | 時間単位の休み | `hourlyLeave` |
| 行事 | event | 学習発表会、習い事の試合など。記録の「事象」とは別 | `event` |
| 連絡帳 | contact notebook (renrakuchō) | 学校と家の間で毎日やりとりする帳面。持ち物・宿題・連絡を書く | `renrakucho` |
| 習い事 | lesson / club activity | 学校の外の教室・クラブ（スイミング、そろばん、サッカー、塾） | `club` |
| 当番 | duty | 家庭が順番に受け持つ役（お茶当番、配車） | `duty` |
| おてがみ（配られたプリント） | handout | 学校で配られた紙。連絡帳には枚数だけ書かれることがある | `handout` |
| テスト | test | 漢字テスト、検定など。何日前に知らせるかは家族が決める | `test` |
| 宿題・サイン | homework / parent signature | 音読カードのサインのように、家の人がする物を含む | `homework` |
| 事象 | log entry | 記録の一件（取り込み、引き受け、時計の進み等）。画面には出さない | `DomainEvent` |
| 所属 | enrollment | 子が通う所（学校・園・学童・習い事・塾）と、その始まりと終わりの日 | `enrollment` |
| 回 | session | 習い事・塾の決まりから導く、ある日の一回。一回の中止と、決まりの変更は別 | `occurrence` |
| 決まり（習い事の） | club rule | 「試合の日はユニフォーム」「月謝は1日まで」のような、回ごとに効く決まり | `clubRule` |
| 分担の決まり | sharing rule | 作業の種類ごとに、誰に提案するかの家族の決まり | `sharingRule` |
| まわりの店と施設 | nearby places | 家族が使える店・郵便局・診療所・薬局・通販。営業時間には出どころと調べた時刻を付ける | `resource` |
| 提案の控え | what you agreed to | 引き受けた時に画面で見せた中身（時刻・帰り・場所・相手）。中身が変われば確かめ直す | `proposalSnapshot` |
| 世代 | round | 取り消しを伝えた物が、また要るようになった時の数え。前の引き受けは引き継がない | `generation` |

## 画面

| 日本語 | English | 意味・注意 |
|---|---|---|
| 今週 | This week | 首の画面。上に次の決め時と今日、下に7日 |
| 全体 | Overview | 4週間の見通しと、行事ごとの準備の鎖 |
| 取り込む | Add | お知らせを文・写真で入れる |
| 家族 | Family | 成員、場所、ふだんの週、決まり |
| 初めの設定 | Setup | 家・学校と学童・職場・通勤・お迎えの担当 |
| 次の決め時 | Next decision | 首の画面の一番上 |
| 変わったこと | What changed | 変更の差分 |
| ひとこと | Quick update | 「きょう」の上の欄。家族の一言から、どの頼み事・作業・未定の値のことかを探して記録の案を出す。押すまで記録しない（デモと、家族の試しの家庭） |
| 話す | Speak | ひとこと・お知らせの欄の押しボタン。ブラウザや端末の音声認識で一回の発話を文字にし、欄の今の文字の後ろに足す（声がその提供元に送られることがある。アプリが受け取るのは文字だけ）。長くなっても切らない。このアプリが文字を送るのは、家族が「伝える」「読み取る」を押した時だけ。認識が無いブラウザでは出さず、キーボードのマイクを案内する |
| やり方を足す | Add a way | 「うちのこと」か「すること」の画面から、家族がやり方の表を埋めて足す。分からない欄は「分からない」のまま。保存の前に変わることを見る |
| やり方をやめる | Stop using a way | これからは新しく選べないようにする（消さない）。今選んである「すること」の選び・作業・頼み事は替えない。使い直せる |
| Claude に案を出してもらう | Ask Claude for ideas | 「すること」の画面から、Claude にやり方の案を出してもらう（デモと、家族の試しの家庭）。送る物を押す前に見せる。案を表に入れる時、Claude に分からない欄は家族が選ぶまで保存しない |
| 分からない | Not known | 家族が値を知らない欄（やり方の代償など）。0・決まり無しに置き換えず、勧める理由にしない |
| することを足す | Add something to do | 「きょう」から、家族の言ったことの原文と欄で「すること」を足す。保存の前に変わることを見る |
| 日は、相手の答えで決める | Decide the day from people’s answers | 「することを足す」で、窓の日を一つに決めず、候補を出す |
| 一人ずつの答えるリンク | answer link, one per person | 家の外の人がログインせずに候補に答える頁（/answer）へのリンク。デモの家庭だけ。出した時に一度だけ見せる。出し直すと前のリンクは使えない |
| 中身を直す | Edit details | 計画に入っている「すること」の欄（何を・日・時刻・だれのため）を直す。形は替えない。保存の前に変わること（やり方の選び直し・頼んだ相手への確かめ）を見る |
| 要らないにする | Mark as not needed | 計画に入っている「すること」を外す。保存の前に変わること（要らなくなる引き受け・頼んだ相手への取り消しの連絡）を見る。消さない |
| 読み取りを確かめる | Check the reading | 「きょう」の札。お知らせから読んだ「すること」を、元の文と並べて家族に確かめてもらう（合っている・直す・読み取りが違う・うちには要らない）。確かめるまで計画に入れない |
| 読み取りが違う | Misread | 確かめる札で、読み取りを外す。計画に入れず、読み直したら、また確かめてもらう |
| もしも | What if | 条件を一つ変えて計算し直す |
| デモの時計 | Demo clock | 試験とデモで進められる時計。進めたことを画面に示す |
